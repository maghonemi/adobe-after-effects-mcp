# AI Interaction UI Kit - Template Skill

This skill provides complete documentation for the "AI Interaction UI Kit" After Effects template - a professional motion graphics template for creating AI product promotional videos.

---

## Template Overview

| Property | Value |
|----------|-------|
| **Resolution** | 3840x2160 (4K UHD) |
| **Frame Rate** | 24 fps |
| **Duration** | 20 seconds per scene |
| **Theme** | Light & Dark (via Color compositions) |
| **Total Compositions** | 67 |
| **Design Style** | Modern, minimal, glassmorphism, gradient glows |

---

## Scene Library

The template includes 7 unique UI scenes, each with full animations:

### Scene 01: Ask/Search Interface
- **Main Comp**: `01 UI Ask - Color` (22 layers)
- **Animation Comp**: `01 UI - All` (9 layers)
- **Purpose**: AI prompt/search bar with typing animation
- **Key Elements**: Search bar, circular icon, tab navigation
- **Animation Style**: Slide-in from bottom, cursor blink

### Scene 02: Desktop Dashboard
- **Main Comp**: `02 UI Desktop - Color` (26 layers)
- **Animation Comp**: `02 UI - All` (4 layers)
- **Purpose**: Full desktop interface with sidebar and content
- **Key Elements**: Welcome message, user profile, content cards, description text
- **Animation Style**: Staggered fade-in, scroll reveal

### Scene 03: Feature List
- **Main Comp**: `03 UI List - Color` (18 layers)
- **Animation Comp**: `03 UI - All` (25 layers)
- **Purpose**: Animated list of features/benefits
- **Key Elements**: Main heading, 4 feature rows with icons
- **Animation Style**: Sequential row reveals with cursor interaction

### Scene 04: Generate/Create
- **Main Comp**: `04 UI Generate - Color` (18 layers)
- **Animation Comp**: `04 UI Generate - All` (11 layers)
- **Purpose**: Content generation interface
- **Key Elements**: Input field, generate button, loading animation
- **Animation Style**: Type-on effect, button pulse

### Scene 05: Mobile Phone
- **Main Comp**: `05 UI Phone - Color` (30 layers)
- **Animation Comp**: `05 UI Phone - All` (4 layers)
- **Purpose**: Mobile app interface mockup
- **Key Elements**: Phone frame, app header, content area, input field
- **Animation Style**: Phone slide-in, content fade

### Scene 06: CTA Button
- **Main Comp**: `06 UI Button - Color` (18 layers)
- **Animation Comp**: `06 UI Button - All` (12 layers)
- **Purpose**: Call-to-action with animated button
- **Key Elements**: Large button with gradient glow, cursor hover effect
- **Animation Style**: Scale pulse, gradient animation, cursor click

### Scene 07: Voice Assistant
- **Main Comp**: `07 UI Voice assistant - Color` (18 layers)
- **Animation Comp**: `07 UI Voice assistant - All` (21 layers)
- **Purpose**: AI conversation/chat interface
- **Key Elements**: Microphone icon, chat bubbles, typing indicator
- **Animation Style**: Message cascade, waveform animation

## Animation Patterns

### Null Object Control System
The template uses null objects as animation controllers:
- `Null transition` - Controls scene entrance/exit
- `Null tab` - Controls tab/button group animations
- `Null cursor` - Controls cursor movement paths
- `Null text+button` - Groups text and button elements

**Pattern**: Animate the null, child layers inherit movement.

### Common Animation Timings

| Animation Type | Duration | Easing |
|----------------|----------|--------|
| Scene entrance | 0.5-1s | Ease Out |
| Element fade in | 0.3-0.5s | Ease In Out |
| Stagger delay | 0.08-0.15s | Per element |
| Cursor movement | 0.5-0.8s | Ease In Out |
| Button hover | 0.2-0.3s | Ease Out |
| Text reveal | 0.4-0.6s | Ease Out |

### Keyframe Patterns

**Slide In From Bottom**:
```
Position keyframes:
  0s: [x, y+200]
  0.5s: [x, y] with Ease Out
```

**Fade In**:
```
Opacity keyframes:
  0s: 0%
  0.3s: 100% with Ease In Out
```

**Scale Pop**:
```
Scale keyframes:
  0s: [90, 90]
  0.3s: [102, 102] with Ease Out
  0.5s: [100, 100] with Ease In Out
```

**Staggered List Reveal**:
```
For each row (i = 0, 1, 2, 3...):
  Start time: i * 0.1s
  Opacity: 0 → 100 over 0.3s
  Position Y: +30 → 0 over 0.4s
```

## Visual Design System

### Color Palette
The template uses expression controls for easy color customization:

| Element | Light Theme | Dark Theme |
|---------|-------------|------------|
| Background | Light gray gradient | Dark gradient |
| Primary text | Dark gray (#1a1a1a) | White (#ffffff) |
| Secondary text | Medium gray (#666666) | Light gray (#aaaaaa) |
| Accent | Purple/Blue gradient | Purple/Blue gradient |
| Button fill | Dark (#1a1a1a) | Dark (#1a1a1a) |
| Button glow | Multi-color gradient | Multi-color gradient |

### Gradient Glow Effect (Scene 06 Button)
The signature button effect uses:
- Shape layer with rounded rectangle
- Gradient stroke (purple → blue → orange)
- Gaussian blur on duplicate layer
- Blend mode: Add or Screen
- Animated rotation on gradient

### Background Style
All backgrounds use:
- Subtle radial gradients
- Light/dark theme variants
- Soft shadows and depth
- Glassmorphism overlays (optional)

## Workflow: Creating a Promo Video

### Step 1: Update Text Content
```yaml
Tool: set-text-content
Parameters:
  compIndex: [text comp index from table above]
  layerIndex: 1
  text: "Your custom text"
```

### Step 2: Create Main Composition
```yaml
Tool: create-composition
Parameters:
  name: "My Promo Video"
  width: 3840  # or 1280 for 720p
  height: 2160  # or 720 for 720p
  duration: 30
  frameRate: 24
```

### Step 3: Add Scenes as Layers
```yaml
Tool: add-comp-as-layer
Parameters:
  targetCompName: "My Promo Video"
  sourceCompName: "01 UI Ask - Color"
  layerName: "Scene 01"
```

### Step 4: Set Scene Timing
For a 30-second video with smooth transitions:

| Layer | Scene | Start | Duration | Overlap |
|-------|-------|-------|----------|---------|
| 5 | Scene 01 | 0s | 6s | - |
| 4 | Scene 02 | 5.5s | 7s | 0.5s |
| 3 | Scene 03 | 12s | 6s | 0.5s |
| 2 | Scene 04 | 17.5s | 7s | 0.5s |
| 1 | Scene 05 | 24s | 6s | 0.5s |

```yaml
Tool: layer-set-timing
Parameters:
  compName: "My Promo Video"
  layerIndex: 5
  startTime: 0
  inPoint: 0
  outPoint: 6
```

### Step 5: Add Cross-Dissolve Transitions
```yaml
Tool: set-keyframes
Parameters:
  compIndex: [main comp index]
  layerIndex: [layer index]
  propertyPath: "Opacity"
  keyframes:
    - time: [start], value: 0
    - time: [start + 0.5], value: 100
    - time: [end - 0.5], value: 100
    - time: [end], value: 0
```

### Step 6: Create 720p Version (Recommended)
```yaml
# Create 720p composition
Tool: create-composition
Parameters:
  name: "My Promo 720p"
  width: 1280
  height: 720
  duration: 30
  frameRate: 24

# Nest 4K comp inside
Tool: add-comp-as-layer
Parameters:
  targetCompName: "My Promo 720p"
  sourceCompName: "My Promo Video"
  layerName: "4K Source"

# Scale to fit
Tool: transform-fit-to-comp
Parameters:
  compIndex: [720p comp index]
  layerIndex: 1
  fitType: "fit"
```

### Step 7: Save Project
```yaml
Tool: save-project
Parameters:
  savePath: "/path/to/project.aep"
```

### Step 8: Render
```yaml
# Check available templates first
Tool: list-output-templates

# Add to render queue with H.264
Tool: add-to-render-queue
Parameters:
  compIndex: [comp index]
  outputModule: "H.264 - Match Render Settings - 15 Mbps"
  outputPath: "/path/to/output.mp4"

# Start render
Tool: start-render
```

## Troubleshooting

### Text Not Updating
- Edit the TEXT composition (Text XX-XX), not the UI composition
- Use correct compIndex from reference table
- Layer index is always 1 for text compositions

### Scene Appears Black/Empty
- Check layer opacity keyframes
- Verify inPoint/outPoint timing
- Ensure source composition exists

### 720p Shows Wrong Positioning
- Use nested composition approach
- Add 4K comp as layer, then transform-fit-to-comp
- Don't resize composition after adding scene layers directly

### Render File Too Large
- Use H.264 output module instead of Lossless
- Create 720p version for web
- Use 5 Mbps for smallest size

### Animation Not Playing
- Check if layer is enabled
- Verify parent null object keyframes
- Check composition work area
