## 2. Project Setup Workflow

### Step 1: Initialize Project

**Prompt:**
```
Create a new After Effects project and set up a main composition with these specs:
- Name: [Your Project Name]
- Resolution: 1920x1080 (or 1080x1080 for Instagram, 1080x1920 for TikTok)
- Frame Rate: 30fps
- Duration: [X] seconds
- Background Color: [color or transparent]
```

**What happens:**
1. Creates new project
2. Sets project settings (bit depth, color management)
3. Creates main composition
4. Organizes project folders

### Step 2: Create Project Structure

**Prompt:**
```
Set up the project organization:
1. Create a folder called "Assets" for imported files
2. Create a folder called "Comps" for sub-compositions
3. Create a folder called "Precomps" for nested compositions
4. Create an adjustment layer for global color grading
```

### Step 3: Import Assets (if needed)

**Prompt:**
```
Import these files into the project:
- Logo: /path/to/logo.png
- Background: /path/to/background.mp4
- Music: /path/to/music.mp3
```

```

```
Create kinetic typography sequence with text:
"[LINE 1]"

"[LINE 3]"

- Exit with slide out

## 5. Animation Recipes

### Bounce In
```
Animate layer with bounce-in effect:
- Property: Scale
- Start value: [0, 0]
- Overshoot to: [120, 120] at 60%
- Settle to: [100, 100]
- Duration: 0.8 seconds
- Use expression or keyframes with custom easing
```

### Elastic Pop
```
Animate layer with elastic pop:
- Scale from 0 to 100 with elastic overshoot
- Add slight rotation wobble (-5 to 5 degrees)
- Duration: 1 second
- Apply to all text layers in sequence with 0.1s delay
```

### Smooth Slide
```
Animate layer sliding in:
- Start position: off-screen [left/right/top/bottom]
- End position: final position
- Easing: ease-out cubic
- Duration: 0.5 seconds
```

### Fade Through
```
Create crossfade transition:
- Layer A: Fade opacity from 100 to 0
- Layer B: Fade opacity from 0 to 100
- Overlap: 0.5 seconds
- Add slight scale (100 to 105) on outgoing
```

### Parallax Scroll
```
Create parallax effect with 3 layers:
- Background: Move slowest (position Y: 0 to -100)
- Midground: Move medium (position Y: 0 to -200)
- Foreground: Move fastest (position Y: 0 to -400)
- Duration: 5 seconds
- Creates depth illusion
```

### Logo Reveal
```
Create logo reveal animation:
1. Start with logo at scale 0
2. Quick scale to 110% with ease-out
3. Settle to 100% with slight bounce
4. Add light sweep effect (CC Light Sweep)
5. Optional: particle burst behind logo
Duration: 2 seconds
```

### Text Stagger
```
Animate multiple text lines with stagger:
- Line 1: Starts at 0s
- Line 2: Starts at 0.15s
- Line 3: Starts at 0.3s
- Each line: fade in + slide up 30px
- Duration per line: 0.4s
```

## 7. Prompt Engineering Guide

### Best Practices for AI Prompts

#### Be Specific About Timing
```
❌ "Add some text animation"
✅ "Add text at 2 seconds, animate over 0.5s with fade-in from bottom"
```

#### Specify Exact Values
```
❌ "Make it bigger"
✅ "Scale to 150% over 0.3 seconds with ease-out"
```

#### Describe Animation Style
```
❌ "Animate the logo"
✅ "Animate logo with: scale 0→110→100 (bounce), rotation -10→0, blur 20→0, over 1.5 seconds"
```

#### Include Color Codes
```
❌ "Use brand colors"
✅ "Use colors: primary #FF6B35, secondary #004E89, accent #FFFFFF"
```

#### Specify Layer Order
```
❌ "Add text and background"
✅ "Add background solid at bottom layer, then text layer on top. Background: #1a1a2e, Text: white"
```

### Prompt Templates

#### New Composition
```
Create a new composition:
- Name: "[NAME]"
- Size: [WIDTH]x[HEIGHT]
- Frame Rate: [FPS]fps
- Duration: [X] seconds
- Background: [COLOR or transparent]
```

#### Text Layer
```
Create a text layer:
- Text: "[YOUR TEXT]"
- Position: ([X], [Y])
- Font: [FONT NAME]
- Size: [SIZE]px
- Color: [HEX COLOR]
- Animation: [ANIMATION TYPE] over [DURATION]s starting at [TIME]s
```

#### Shape Layer
```
Create a shape layer:
- Shape: [rectangle/ellipse/polygon/star/custom]
- Size: [WIDTH]x[HEIGHT]
- Position: ([X], [Y])
- Fill: [HEX COLOR]
- Stroke: [HEX COLOR], [WIDTH]px
- Animation: [describe animation]
```

#### Keyframe Animation
```
Animate [LAYER NAME]:
- Property: [position/scale/rotation/opacity]
- At [TIME1]s: [VALUE1]
- At [TIME2]s: [VALUE2]
- Easing: [linear/ease-in/ease-out/ease-in-out/bounce/elastic]
```

#### Effect
```
Apply effect to [LAYER NAME]:
- Effect: [EFFECT NAME]
- Settings: [PROPERTY]: [VALUE]
- Animate [PROPERTY] from [START] to [END] over [DURATION]s
```

## 8. Troubleshooting

### Common Issues

#### "Animation doesn't look smooth"
**Solution Prompt:**
```
Apply ease-in-out easing to all keyframes on [LAYER NAME].
Set influence to 75% for smoother motion.
```

#### "Text is hard to read"
**Solution Prompt:**
```
Add a drop shadow to [TEXT LAYER]:
- Distance: 5px
- Softness: 10px
- Opacity: 50%
- Color: #000000

Or add a dark semi-transparent shape behind the text.
```

#### "Animation timing feels off"
**Solution Prompt:**
```
Adjust timing for [LAYER NAME]:
- Move all keyframes [X] seconds [earlier/later]
- Extend animation duration to [X] seconds
- Add 0.1s delay between staggered elements
```

#### "Colors don't match brand"
**Solution Prompt:**
```
Update colors across project:
- Replace all instances of [OLD COLOR] with [NEW COLOR]
- Apply color correction adjustment layer with:
  - Hue shift: [X] degrees
  - Saturation: [X]%
```

#### "Need to make it loop"
**Solution Prompt:**
```
Make composition loop seamlessly:
- Duplicate first frame's state to last frame
- Add 0.5s crossfade at the end
- Ensure all animated elements return to start positions
```

### Performance Tips

```
For complex projects:
- Precompose heavy effect layers
- Use adjustment layers for effects applied to multiple layers
- Purge memory cache periodically
- Reduce preview resolution while working
```
