## Project Initialization

### 🆕 Start New Project

```
Create a new After Effects project with these settings:
- Project name: [PROJECT_NAME]
- Bit depth: 16-bit
- Create main composition:
  - Name: "Main Comp"
  - Resolution: 1920x1080
  - Frame rate: 30fps
  - Duration: [DURATION] seconds
  - Background: [#HEXCOLOR or "transparent"]
- Create folder structure: "Assets", "Comps", "Audio", "Exports"
```

### 📁 Multi-Composition Project

```
Set up a multi-composition project:

1. Create master composition "Final Output" (1920x1080, 30fps, 60s)
2. Create sub-compositions:
   - "Intro" (1920x1080, 30fps, 5s)
   - "Main Content" (1920x1080, 30fps, 45s)
   - "Outro" (1920x1080, 30fps, 10s)
3. Nest all sub-compositions into master comp in sequence
4. Create adjustment layer on top for color grading
```

## 🚀 Power User Tips

### Combine Multiple Prompts
```
"Execute these in sequence:
1. [First prompt]
2. [Second prompt]  
3. [Third prompt]
Wait for each to complete before the next."
```

### Batch Operations
```
"Apply this animation to all text layers:
[Animation description]
Stagger start time by 0.2s for each layer"
```

### Conditional Logic
```
"If the composition is square format, position text at center.
If 16:9, position text at lower third.
Apply appropriate safe zones."
```

### Reference Existing Elements
```
"Copy the animation style from layer 'Title' and apply it to layer 'Subtitle'
with 0.3s delay"
```
